# Server Deck — полный пул инструментов

Продукт: плагин Stream Deck для мониторинга и управления серверами (VPS, homelab, облако).
Основа: текущий проект `streamdeck-server-status` (HTTP-проверка + CPU/RAM по SSH, чёрно-хромовая тема).

## 1. Боли пользователей и чем их закрываем

Источники: анализ Elgato Marketplace (ноябрь 2026) — Pi Deck, Homelab Monitor, elgato-docker, SSHDeck, Uptime Kuma, Docker Monitor; плюс боли реальной эксплуатации VPS.

| # | Боль | Откуда известна | Чем закрываем |
|---|---|---|---|
| 1 | Нет алертов и истории: «узнал о падении случайно» | Pi Deck сам пишет «нет истории и алертов» | Движок алертов, sparkline, журнал инцидентов |
| 2 | Всё заточено под homelab/Raspberry, не под VPS с сайтами | Pi Deck, Homelab Monitor | HTTP/TLS/порты, nginx, PM2, PostgreSQL, бэкапы |

| 5 | Страх нажать опасное (reboot, reload nginx) | практика: ошибка в nginx-конфиге роняет все сайты | Hold-to-confirm, `nginx -t` перед reload, режим «только чтение» |

| 14 | Ночью/на встрече алерты мешают | — | Snooze, тихие часы, acknowledge |

## 2. Архитектура

### Слои
1. **Hosts** — реестр серверов в Global Settings плагина. Источник: импорт `~/.ssh/config` или ручной ввод. Секреты не храним: только ключи/ssh-agent.
2. **Collector** — на хост один долгоживущий `ssh host 'sh -s'`, в stdin уходит скрипт-коллектор, он раз в N секунд печатает JSON-строки (CPU, RAM, диск, load, сеть, сервисы). Нет повторных рукопожатий (на Windows нет ControlMaster), нагрузка и шум в логах sshd минимальны, на сервере ничего не устанавливается.
3. **Checks** — проверки с клиента (HTTP, TCP, TLS, DNS) без SSH.
4. **State store** — кольцевой буфер (например, 24 ч) на метрику → sparkline, прогнозы, гистерезис.
5. **Alert engine** — конечный автомат OK → WARN → CRIT → ACK; задержка (N подряд), гистерезис, snooze; каналы доставки.
6. **Actions** — слой команд с уровнями безопасности (см. раздел 4).
7. **Renderer** — единая тема (чёрный + хром), режимы: ключ, сенсорная полоса, Infobar Neo.

### Принципы
- Два режима хоста: **Observer** (только чтение, по умолчанию) и **Operator** (разрешены действия, включается явно).
- Коллектор только читает (`/proc`, `systemctl`, `docker ps`, `df`). Любая запись идёт через Actions.
- Выбор сервисов в Property Inspector из списка, найденного на сервере, а не вводом руками.
- Работает без интернета (кроме Telegram/webhook).

## 3. Пул инструментов (Actions)

Обозначения: 🆓 бесплатно, ⭐ Pro. Фаза = в какой версии выходит.

### A. Метрики хоста
| Инструмент | Что показывает | Фаза |
|---|---|---|
| Host Overview | CPU, RAM и load на одном ключе, статус хоста (уже есть) | 1 🆓 |
| Metric | Одно значение: CPU, RAM, swap, load, iowait, температура + sparkline | 1 🆓 |
| Disk | Использование по точке монтирования, свободно ГБ, inodes | 1 🆓 |
| Disk Forecast | «Диск заполнится через N дней» по тренду | 2 ⭐ |
| Network | Входящий/исходящий трафик, пакеты, ошибки | 2 🆓 |
| Uptime & Reboot Flag | Аптайм, «нужна перезагрузка», последняя загрузка | 2 🆓 |
| Top Processes | Топ-3 по CPU/RAM; нажатие — ротация | 2 🆓 |
| Latency | Пинг до хоста + sparkline | 1 🆓 |

### B. Доступность (с клиента, без SSH)
| Инструмент | Что делает | Фаза |
|---|---|---|
| HTTP Check | Код, время ответа, поиск ключевого слова, JSON-путь (уже есть, расширить) | 1 🆓 |

| TLS Expiry | Дней до окончания сертификата, цепочка | 1 🆓 |
| Domain Expiry | Дней до окончания домена (RDAP) | 2 🆓 |

## 4. Модель безопасности действий

| Уровень | Примеры | Как защищено |
|---|---|---|
| L0 Чтение | Все метрики и проверки | Без подтверждений |
| L1 Безопасная запись | Restart одного сервиса, clear cache | Удержание 1 с, лог в плагине |
| L2 Опасная | Reboot, Shutdown, Update, Deploy, Rollback | Удержание 2 с + второе нажатие, перед выполнением на ключе видно команду |
| L3 Критичная | Любая пользовательская команда с `rm`, `dd`, `mkfs`, `drop` и т.п. | Блокируется по умолчанию, разрешение только в настройках хоста |

- Хост по умолчанию в режиме Observer: действия L1+ недоступны, пока не включён Operator.
- Защита от ошибок: `nginx -t` перед reload, проверка конфига перед рестартом, откат Deploy при ненулевом коде.
- Ключ действует только на то, что на нём показано (как у Session Keys): сменившийся ключ ничего не отправляет.
- Аудит: каждая запись/действие попадает в лог плагина с временем и результатом.

## 5. Монетизация

- **Free**: Observer-метрики, HTTP/TCP/TLS, systemd, Docker, PM2, Alert Hub, Snooze, Setup Wizard, 1 хост без ограничений на число ключей.
- **Pro**: Fleet, несколько хостов, Incident Log, Disk Forecast, Compose, PostgreSQL/Redis, Telegram/webhook, интеграции, Dial/Touch Strip, Deploy/Rollback.
- Цена ориентира: около $10 (Pi Deck и Homelab Monitor). Решение по цене — после уточнения условий выплат Stripe для страны разработчика. До этого публиковать бесплатно.

## 7. Риски и открытые вопросы

- **Спрос не измерен**: на страницах Marketplace нет рейтингов и скачиваний. Проверять по отзывам после первого релиза.
- **Выплаты**: условия Stripe для страны разработчика не подтверждены.
- **Pi Deck**: сильный конкурент (энкодеры, безопасные удержания). Отличаемся VPS-сценариями, HTTP/TLS, алертами, Docker по SSH, мастером и дизайном.
- **Безопасность**: плагин с правом выполнять команды на серверах — мишень для доверия; нужна прозрачность (открытый список команд, режим Observer, отсутствие телеметрии).
- **Windows-сценарии ssh**: проверить поведение системного `ssh` при смене сети и «засыпании» компьютера (переподключение коллектора).
